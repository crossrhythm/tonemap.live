# Release Note: Free/Pro Split Simplification

Date: 2026-07-10
Version: 2.12

- Hard Mode and Quick Record are now the only Pro-gated features.
- Performance Pitch (A4), History, and Color Hold are free for everyone, including custom A4 values and the longer memory / hold options.
- The Pro overlay and FAQ/help text were updated to match the new split.
- This keeps the web app aligned with the upcoming iOS dual-authorization model, where Pro access can arrive through either Polar or IAP.
