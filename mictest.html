Tonemap Mic Baseline Test

Measures the raw and post-gain mic RMS over a 5-second window using Tonemap's exact input pipeline.

Environment

Setup

  1. Pick a reference tone source (recommended: 1 kHz sine, continuous) and note exactly what it is for the notes column in your sheet.
  2. Play it on a second device at a fixed system volume (recommend 50%) and fixed distance (recommend 30 cm) from this device.
  3. Keep the room quiet and the reference tone unchanged for the full duration of the test (one 5 s run on most devices, two back-to-back 5 s runs on Safari 26.4+).
  4. Re-use the same source / volume / distance for every device you test.
